# Complex Systems Stuff

## What is this?

Exercises, materials, and what-not while I study complex systems. 

## Contents

- `sayama/`: Examples and exercises from "Modelling and Analysis of Complex Systems" by Hiroki Sayama. Python scripts updated to v3.12. Some exercises solved in Julia.
  
- `ODEs/`: Different systems and models using ordinary differential equations and my attempts to solve them.

- `logisticmap.jl`: A simple interactive logistic map visualizer (cobweb plot, bifurcation) made with `Makie.jl`.
